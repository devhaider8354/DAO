# DAO مدير التحميل

[![Build](https://github.com/devhaider8354/DAO/actions/workflows/build.yml/badge.svg)](https://github.com/devhaider8354/DAO/actions/workflows/build.yml)

[English](README.md) | **العربية**

DAO مدير تحميل سريع وخفيف لنظام ويندوز، مكتوب بلغة C باستخدام Win32 API و WinHTTP. يقسّم كل ملف إلى أجزاء ويحمّلها بعدة اتصالات في نفس الوقت، ويستكمل التحميلات المنقطعة، ويرتبط مع متصفحات كروم وإيدج وبريف.

<!-- ![DAO](docs/screenshot.png) -->

## المميزات

- **تحميل متعدد الاتصالات** – حتى 32 اتصالاً متوازياً للملف الواحد باستخدام طلبات HTTP Range.
- **توزيع أحمال ديناميكي** – عندما ينهي اتصال جزءه، يأخذ نصف أكبر جزء متبقٍ، فتبقى كل الاتصالات تعمل حتى آخر الملف.
- **إيقاف واستكمال** – يُحفظ التقدّم كل ثانيتين، والتحميلات تستمر بعد إغلاق البرنامج أو انقطاع الإنترنت أو إعادة تشغيل الجهاز.
- **إعادة محاولة تلقائية** عند أخطاء الاتصال.
- **الربط مع المتصفح** – إضافة كروم تحوّل التحميلات إلى DAO مع الكوكيز والـ Referer، فتعمل حتى التحميلات التي تتطلب تسجيل الدخول.
- **نافذة تحميل جديد** – تعرض اسم الملف وحجمه ودعم الاستكمال ومجلد الحفظ وعدد الاتصالات قبل البدء.
- **مراقبة الحافظة** – انسخ أي رابط وسيظهر في البرنامج تلقائياً.
- **خريطة الأجزاء** – عرض مباشر لكل جزء من الملف أثناء التحميل.
- **واجهة عربية وإنجليزية** مع دعم كامل للاتجاه من اليمين لليسار.
- **واجهة داكنة حديثة** تدعم الشاشات عالية الدقة.
- **بدون أي مكتبات خارجية** – مكتبات ويندوز فقط، وملفات تنفيذية صغيرة.
- تسمية ذكية للملفات: `Content-Disposition`، الأسماء العربية، الأسماء المضمّنة داخل روابط التوكن (JWT)، الامتداد حسب نوع الملف، ومعالجة الأسماء الطويلة.

## التحميل

حمّل `DAO-Setup.exe` من صفحة [Releases](../../releases) وشغّله. المثبّت:

- يثبّت البرنامج في `Program Files\DAO`
- ينشئ اختصارات في قائمة ابدأ وسطح المكتب
- يسجّل الربط مع كروم وإيدج وبريف
- يضيف DAO إلى *الإعدادات ← التطبيقات* مع أداة إزالة كاملة

يتطلب ويندوز 10 أو 11 (64 بت).

## الربط مع كروم

الإضافة موجودة في مجلد [`extension`](extension).

**الطريقة الأولى – تثبيتها يدوياً (مرة واحدة، أقل من دقيقة)**

1. افتح `chrome://extensions` وفعّل **Developer mode** (وضع المطوّر).
2. اضغط **Load unpacked** واختر المجلد `C:\Program Files\DAO\chrome-extension`.
3. أعد تشغيل كروم.

عند تشغيل DAO لأول مرة يظهر دليل لهذه الخطوات (زر **ربط كروم**)، ويتحول للأخضر بمجرد اتصال الإضافة.

**الطريقة الثانية – متجر كروم**

كروم لا يسمح للبرامج بإضافة إضافة تلقائياً إلا إذا كانت منشورة في متجر كروم (وهذه نفس طريقة برامج التحميل الأخرى). بعد النشر، ابنِ المثبّت برقم الإضافة في المتجر، وعندها كروم يطلب من المستخدم فقط الضغط على *تفعيل*:

<div dir="ltr">

```
make STORE_ID=<your-extension-id>
```

</div>

بعد التثبيت، أي تحميل يبدأ في المتصفح يفتح نافذة *تحميل جديد* في DAO بدلاً من كروم. ويمكنك أيضاً الضغط بالزر الأيمن على أي رابط واختيار **تحميل بواسطة DAO**. من نافذة الإضافة يمكنك إيقاف الالتقاط مؤقتاً أو استثناء الملفات الصغيرة أو أنواع ملفات أو مواقع معيّنة. وإذا لم يكن DAO متاحاً، يكمل كروم التحميل بنفسه.

## الاستخدام

| العملية | الطريقة |
| --- | --- |
| إضافة تحميل | الصق الرابط واضغط **Enter** أو **إضافة تحميل** |
| إيقاف / استئناف | **Space** أو أزرار الشريط أو قائمة الزر الأيمن |
| حذف | **Delete** (و Shift+Delete يحذف الملف أيضاً) |
| فتح ملف مكتمل | نقر مزدوج أو **Enter** |
| تغيير اللغة | زر اللغة في أعلى النافذة (English / عربي) |

الإعدادات وقائمة التحميلات محفوظة في `%APPDATA%\DAO`.

### سطر الأوامر

`dao-cli.exe` نسخة مستقلة من المحرك تعمل من سطر الأوامر:

<div dir="ltr">

```
dao-cli "https://example.com/file.zip"
dao-cli "https://example.com/file.zip" -n 16 -o file.zip -d D:\Downloads
```

</div>

اضغط `Ctrl+C` للإيقاف، وأعد تشغيل نفس الأمر للاستكمال.

## البناء من المصدر

**MSYS2 / MinGW-w64**

<div dir="ltr">

```
pacman -S mingw-w64-ucrt-x86_64-gcc make
make
```

</div>

**من لينكس** (مثلاً باستخدام [llvm-mingw](https://github.com/mstorsjo/llvm-mingw))

<div dir="ltr">

```
make CROSS=x86_64-w64-mingw32-
```

</div>

**Visual Studio** – شغّل `build.bat` من *Developer Command Prompt*.

الملفات الناتجة في مجلد `build/`: ‏`dao.exe` و `dao-host.exe` و `dao-cli.exe` و `DAO-Setup.exe`.

<div dir="ltr">

```
  main.c        Win32 UI: main window, download list, dialogs, Chrome setup guide
  engine.c/.h   download engine: probing, segments, workers, resume state

```

## طريقة العمل

1. **الفحص** – طلب `Range: bytes=0-0` يكشف حجم الملف ودعم الأجزاء واسم الملف.
2. **التقسيم** – يُحجز الملف مسبقاً باسم `name.part` ويُقسّم إلى أجزاء متساوية، جزء لكل اتصال.
3. **التحميل** – كل خيط يطلب نطاقه ويكتب في موقعه داخل الملف. وعندما ينتهي خيط من عمله، يقسم أكبر جزء نشط إلى نصفين ويأخذ النصف الثاني.
4. **الاستكمال** – تُحفظ النطاقات المتبقية في `name.dao` كل ثانيتين، وعند الاستكمال تُطلب الأجزاء الناقصة فقط.
5. **الانتهاء** – يُعاد تسمية ملف `.part` إلى الاسم النهائي ويُحذف ملف الحالة.

مسار المتصفح: الإضافة توقف تحميل كروم وترسل الرابط والكوكيز والـ Referer إلى `dao-host.exe` عبر Chrome Native Messaging. يشغّل الجسر برنامج DAO إذا لم يكن يعمل ويمرر الطلب عبر `WM_COPYDATA`، ثم تلغي الإضافة نسخة كروم. وإذا فشل أي شيء، يستكمل كروم تحميله بنفسه.

## المساهمة

البلاغات وطلبات الدمج مرحب بها. يرجى إبقاء الكود بدون مكتبات خارجية (Win32 و WinHTTP فقط)، وإضافة أي نص جديد للواجهة في `src/i18n.c` باللغتين.
